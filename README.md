## 🚀 Обзор проекта
**XALAUNCHER Pro** — это оптимизированный инструмент для запуска Minecraft. Проект сфокусирован на стабильности, быстром доступе к игровым сессиям и отсутствии избыточных фоновых процессов.

### 🌟 Основные характеристики
* **Поддержка версий:** Стабильная работа с Vanilla, Forge и Fabric.
* **Система уведомлений:** Встроенный блок новостей и обновлений для последних версий Minecraft.
* **Оптимизация:** Легкая архитектура, обеспечивающая быстрый запуск приложения.
* **UI/UX:** Лаконичный интерфейс в темных тонах, адаптированный для комфортной работы.

---

## 🛠 Техническая информация
Лаунчер разработан с использованием актуального стека технологий:
* **Язык:** Python 3.x
* **GUI:** PyQt6
* **Ядро запуска:** minecraft-launcher-lib
