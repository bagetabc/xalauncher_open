## 🚀 Обзор проекта
**XALAUNCHER Pro** — это оптимизированный инструмент для запуска Minecraft. Проект сфокусирован на стабильности, быстром доступе к игровым сессиям и отсутствии избыточных фоновых процессов.

## 🌟 Основные характеристики
* **Поддержка версий:** Стабильная работа с Vanilla, Forge и Fabric.
* **Система обновлений:** Встроенный блок новостей для последних версий Minecraft.
* **Оптимизация:** Легкая архитектура и быстрый запуск.
* **UI/UX:** Лаконичный интерфейс в темных тонах.

## 🛠 Техническая информация
* **Язык:** Python 3.x
* **GUI:** PyQt6
* **Ядро:** minecraft-launcher-lib
